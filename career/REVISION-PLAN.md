# DSA Revision Plan — Spaced Repetition

> Every problem is revised at Day 1, Day 3, Day 7, and Day 14 after solving.
> Revision = explain pattern + key insight + complexity in 30 seconds.
> If you can't explain → re-read note (2 min). Still can't → re-solve (15 min).

---

## How It Works

### Daily Schedule

```text
Morning (5:15–7:15):
  First 20 min:  Revision (problems due today)
  Remaining:     2–3 new problems

Evening (6:30–8:00):
  Java / Spring / System Design

Night (8:45–9:45):
  DDIA / HLD
```

### Revision Effort by Day

```text
Day 1 revision:  Say pattern + approach out loud (30 sec per problem)
Day 3 revision:  Write pseudocode on paper without notes (2 min per problem)
Day 7 revision:  Re-solve on blank editor without any reference (10 min per problem)
Day 14 revision: Quick recall — if instant, mark as mastered (10 sec per problem)
```

```text
  + 3 new problems
  + 30 min Java/Spring/SD
```

The revision schedule auto-generates from solve dates:

```text
Solve on Day X →
  Revise on Day X+1 (say approach)
  Revise on Day X+3 (write pseudocode)
  Revise on Day X+7 (re-solve blank)
  Revise on Day X+14 (quick recall → mark mastered or flag weak)
```

---

## Revision Levels

```text
Level 1 (Day 1):   Can explain pattern + approach? (30 sec)
Level 2 (Day 3):   Can write pseudocode without notes? (2 min)
Level 3 (Day 7):   Can re-solve on blank editor? (10 min)
Level 4 (Day 14):  Instant recall? → MASTERED
                   Can't recall? → Reset to Level 1
```
